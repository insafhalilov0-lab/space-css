# space-css

Страница про космос с использованием HTML и CSS.

## Что использовал
- HTML: заголовки, параграфы, жирный текст, курсив, ссылки
- CSS: селекторы по тегу и классу, псевдокласс `:hover`

## Чему научился
- Подключать внешний файл CSS через `<link>`
- Менять цвет текста, убирать подчёркивание у ссылок
- Работать с приоритетами (класс сильнее тега)
- Делать эффект при наведении (`:hover`)
